How to setup:
1. Install the Arduino IDE:
1.1 https://www.arduino.cc/en/software/
1.2 Click 'Just Download' on each page that pops up next.
1.3 Run the installer.

2. Install the 'ESP32' Definitions (Can take a while)
2.1 https://randomnerdtutorials.com/installing-the-esp32-board-in-arduino-ide-windows-instructions/
2.1.1 Add this to 'Additional Boards' https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
2.2 Install all of the USB drivers that come up.

3. Select the correct board
3.1 'ESP32 Dev Module'

4. Setting Up Library Files
4.1 File -> Preference -> Sketchbook Location -> "C:\Whereever you set this folder up"
